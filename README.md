# بيانات شبكة برامج راديو الأوائل 97.5 FM

هذا المستودع هو **المصدر الرسمي** لشبكة برامج الإذاعة. تطبيق الموبايل
يقرأ منه مباشرةً، فأي تعديل هنا يظهر للمستمعين خلال دقائق.

> **مهم:** النسخة الموجودة داخل التطبيق (`Resources/Raw/schedule.json`)
> ليست المصدر — دورها فقط أن تُظهر شيئاً في أول تشغيل بلا إنترنت.
> عدّل هنا دائماً، لا هناك.

## قبل أن تعدّل — اقرأ هذا

**الملف يُقرأ آلياً، فخطأ فاصلة واحد قد يُفرغ صفحة البرامج لكل المستخدمين.**
لذلك يوجد مدقّق تلقائي: بعد كل تعديل تجد علامة ✓ خضراء أو ✗ حمراء بجوار
اسم الـ commit في صفحة المستودع. **إن رأيت ✗ فالتعديل فيه خطأ — افتحها
واقرأ السبب وأصلحه فوراً.**

للفحص قبل الرفع (إن كان Python مثبتاً عندك):

```bash
python validate_schedule.py
```

## بنية الملف

```json
{
  "version": 1,
  "updatedAt": "2026-08-08T12:00:00+03:00",
  "timeZone": "Asia/Baghdad",
  "utcOffsetHours": 3,
  "programs": [ ... ],
  "overrides": [ ... ]
}
```

### برنامج واحد

```json
{
  "id": "sabah-alawael",
  "name": "صباح الأوائل",
  "host": "اسم المقدّم",
  "description": "وصف قصير يظهر تحت اسم البرنامج",
  "image": "images/sabah.png",
  "isActive": true,
  "slots": [
    { "days": ["sun","mon","tue","wed","thu"], "start": "08:00", "end": "10:00" }
  ]
}
```

| الحقل | ملاحظات |
|---|---|
| `id` | **لا تغيّره بعد النشر** — يربطه بالاستثناءات. حروف إنجليزية وشرطات، فريد لكل برنامج |
| `name` | مطلوب — يظهر في التطبيق |
| `host` | اختياري — يُخفى إن كان فارغاً |
| `image` | اختياري — مسار نسبي داخل `images/` أو رابط كامل |
| `isActive` | `false` يُخفي البرنامج بلا حذفه (مفيد للبرامج الموقوفة مؤقتاً) |
| `slots` | مواعيد أسبوعية متكررة — برنامج بلا `slots` لا يظهر |

### قواعد الأيام والأوقات

- الأيام: `sun` `mon` `tue` `wed` `thu` `fri` `sat` — **بالإنجليزية المختصرة فقط**
- الأوقات: `HH:mm` بنظام **٢٤ ساعة** بتوقيت بغداد. `20:00` لا `8:00 PM`
- **البرنامج العابر لمنتصف الليل:** اكتب `"start": "23:00", "end": "01:00"` —
  النظام يفهم تلقائياً أن الانتهاء في اليوم التالي
- برنامج له موعدان مختلفان؟ أضف عنصرين في `slots`:

```json
"slots": [
  { "days": ["sun","tue"], "start": "08:00", "end": "10:00" },
  { "days": ["fri"],       "start": "20:00", "end": "22:00" }
]
```

## الاستثناءات — تعديل يوم واحد بلا تغيير الشبكة

للعُطل والأعياد وشبكة رمضان والحلقات الخاصة.

### إلغاء برنامج في تاريخ محدد

```json
{ "date": "2026-08-17", "type": "cancelled",
  "programId": "sabah-alawael", "note": "عطلة رسمية" }
```

### استبدال برنامج ببرنامج آخر

```json
{ "date": "2026-08-17", "type": "replaced",
  "programId": "sabah-alawael", "withProgramId": "quran-kareem",
  "note": "بمناسبة العيد" }
```

### حلقة خاصة في وقت غير معتاد

```json
{ "date": "2026-08-20", "type": "special",
  "programId": "diwan-alawael", "start": "10:00", "end": "12:00",
  "note": "حلقة خاصة" }
```

> **أكثر خطأ يتكرر:** وضع استثناء `cancelled` على تاريخ لا يُبثّ فيه
> البرنامج أصلاً (مثلاً إلغاء برنامج أيام العمل في يوم جمعة). الاستثناء
> يُتجاهل بصمت وتظن أنك ألغيته. **المدقّق يمسك هذه الحالة تحديداً**
> ويرفض التعديل — فانظر إلى العلامة الحمراء ولا تتجاهلها.

بعد مرور التواريخ يمكن حذف الاستثناءات القديمة لتنظيف الملف.
